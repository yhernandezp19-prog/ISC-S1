# ISC-S1
## Glosario de 15 palabras 

#### APIs
###### Es un intermediario basado en un conjunto de reglas y protocolos  que ayuda a conectar 2 aplicaciones de software se comuniquen entre sí y cumplan con ayudar al usuario con su solicitud según lo solicitado.

#### Docker
###### Es una herramienta que ayuda al usuario a aguardar y ** empaquetar **  su aplicación / software en un contenedor virtual para poder transportarlo y ejecutarlo en diferentes sistemas operativos o software de creación sin necesidad de ajustarlo a dicho  sistema.

#### Phishing
###### Es una técnica maliciosa virtual que engaña al usuario para poder obtener cualquier tipo de información que afecte a este a través de suplantar la identidad por una entidad reconocida.

#### DeVops
###### Integra los procesos de desarrollo y proceso para poder mejorar un ciclo continuo de actualizaciones para un software y este pueda procesar de forma rápida y efectiva evitando fallos en su uso, esto ayuda a mantener una software veloz y de calidad. 

#### EUFI
######  Es el primer programa que se ejecuta al momento de encender el equipo de cómputo, este es un ** puente ** que ayuda a conectar de mejor manera el Hardware con el sistema operativo para que este pueda arrancar de mejor manera.

#### Firmware
###### Es un sistema operativo integrado en los componentes de hardware para que estos puedan funcionar correctamente con el sistema operativo del dispositivo electrónico.

#### Sistema Embebido
###### Es un sistema de software y hardware para que un equipo ( maquinaria mayormente) realice una tarea en especial, estos están compuestos por dispositivos de salida y entrada, microprocesador y almacenamiento. 

#### IoT
###### Es un sistema de dispositivos que poseen un software para compartir datos a otros sistemas o dispositivos a través de una red inalámbrica.

#### BIOS
###### Es un Firmware de entrada y salida instalado principalmente en un chip en la placa madre de los dispositivos con la finalidad de asegurar la buena funcionalidad de los demás periféricos ( CPU, GPU, RAM, ETC..)  y el sistema operativo.

#### IaaS
######  Por sus siglas en Infraestructura como servicio, el cual hace referencia a alquilar un sistema de Hardware (equipo de cómputo, red, app) en lugar de comprar el mismo servicio. 

#### PaaS
###### Hace referencia al alquiler de una herramienta ya programada y lista para utilizarse para evitar crear un servidor, sistema operativo entre otros…  desde cero y poder acelerar el proceso de sacar un nuevo servicio al mercado.


#### SaaS
######   Es un modelo de software en la nube que permite al usuario utilizar un servicio sin necesidad de descargar nada, únicamente utilizar el sistema según su función. 

#### Ciberseguridad
######  Es el conjunto de procesos programados para evitar diferentes ataques que perjudiquen la información del usuario en la red o sistema operativo evitando Phishing, Ransomware y Malware.

#### Circuitos Integrados
###### Son pequeños dispositivos que combinan grandes capacidades de componentes electrónicos con la finalidad de dar potencia y funcionalidad de gran eficiencia en equipos compactos y evitar dispositivos de alta magnitud. 

#### Web
######  World wide web es un sistema de información que utiliza internet para poseer acceso a documentos, imágenes, vídeo, contenido en general a través de un navegador, ayuda a comunicar e informar al usuario según su búsqueda.
